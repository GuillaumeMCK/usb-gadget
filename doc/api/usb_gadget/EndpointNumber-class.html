EndpointNumber

EndpointNumber class

Endpoint number (0-15).

USB devices can have up to 16 endpoint numbers (0-15). Each endpoint number can have both an IN and OUT endpoint, making up to 32 total endpoints per device (though endpoint 0 is bidirectional control only).

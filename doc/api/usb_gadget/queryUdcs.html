List<Udc> queryUdcs()

Gets the available USB device controllers (UDCs) in the system.

Scans /sys/class/udc/ and returns a list of all available UDCs. Returns an empty list if no UDCs are found or sysfs is not available.

Example:

final udcs = queryUdcs();
if (udcs.isEmpty) {
  print('No UDCs available');
}

Implementation

List<Udc> queryUdcs() {
  const classDir = '/sys/class';
  if (!Directory(classDir).existsSync()) {
    return [];
  }

  const udcDir = '$classDir/udc';
  final dir = Directory(udcDir);
  if (!dir.existsSync()) {
    return [];
  }

  final udcs = <Udc>[];
  for (final entry in dir.listSync()) {
    if (entry is Directory) {
      udcs.add(Udc._(entry));
    }
  }

  return udcs;
}

GadgetConfiguration

GadgetConfiguration class final

A gadget configuration containing functions and attributes.

A configuration is a set of functions that can be selected by the USB host. Most gadgets have a single configuration (index 1), but multiple configurations allow the host to choose between different sets of functions.

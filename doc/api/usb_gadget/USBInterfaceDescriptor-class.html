USBInterfaceDescriptor class

USB Interface Descriptor.

Describes a logical grouping of endpoints that perform a related function within a USB device configuration. An interface represents a single function (like mass storage, audio input, etc.) and can have multiple alternate settings to provide different bandwidth or endpoint configurations.

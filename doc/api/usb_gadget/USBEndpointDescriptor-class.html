USBEndpointDescriptor class

USB Endpoint Descriptor.

Describes a USB endpoint within an interface. Endpoints are the ultimate source or sink of data in USB transfers. Each endpoint has a unique address within a device and specific transfer characteristics.

By default this produces a standard 7-byte descriptor (bLength = 7). When bRefresh or bSynchAddress are non-zero (USB Audio Class usage), bLength becomes 9 to include those extra fields.

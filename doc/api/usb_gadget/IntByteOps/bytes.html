bytes property

Uint8List get bytes

Returns all significant bytes of this integer as a Uint8List.

The bytes are returned in little-endian order (least significant byte first). At least one byte is returned, even for the value 0.

Implementation

Uint8List get bytes {
  final byteCount = bitLength == 0 ? 1 : (bitLength + 7) ~/ 8;

  final byteList = Uint8List(byteCount);
  for (var i = 0; i < byteCount; i++) {
    byteList[i] = byte(i);
  }

  return byteList;
}

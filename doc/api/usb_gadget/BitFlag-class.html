BitFlag

BitFlag class abstract

Base class for defining enum-based bit flags.

This abstract class provides a foundation for creating type-safe flag enums where each flag represents a specific bit or bit pattern in an integer.

Typically used with Dart enums to create sets of flags that can be combined using bitwise operations.

Example:

enum Status extends BitFlag {
  active(1 << 0),    // 0b0001
  pending(1 << 1),   // 0b0010
  archived(1 << 2);  // 0b0100
  const Status(super.value);
}

final combined = Status.active.value | Status.pending.value; // 0b0011
final hasActive = (combined & Status.active.value) != 0;     // true
